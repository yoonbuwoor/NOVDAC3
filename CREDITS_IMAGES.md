## Données météo

Le Field Kit utilise l’API **Open-Meteo** pour les conditions météorologiques locales. Les données sont distribuées sous licence **CC BY 4.0** et l’attribution est affichée dans l’application. La Free API est adaptée à l’usage éducatif/non commercial dans les limites publiées par Open-Meteo ; un usage commercial doit respecter l’offre et les conditions en vigueur.
