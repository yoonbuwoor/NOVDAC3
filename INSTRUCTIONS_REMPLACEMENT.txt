DRONEATLAS ACADEMY — MISE A JOUR MOBILE

Ce ZIP contient uniquement les fichiers nouveaux ou modifies.

INSTALLATION
1. Decompressez le ZIP a la racine du depot GitHub NOVDAC.
2. Acceptez le remplacement des fichiers existants.
3. Conservez exactement les dossiers lib/, assets/, android/ et tool/.
4. Faites Commit changes.
5. Relancez GitHub Actions pour generer l APK.

IMPORTANT
- Les icones sont presentes dans android/ ET tool/ car le workflow peut recreer la plateforme Android.
- Le simulateur bloque son echelle typographique a 100 % afin d eviter les polices geantes.
- Les alertes ANACIM sont pedagogiques et ne remplacent pas le texte officiel ni une autorisation.
- Le lien WhatsApp ouvre maintenant le groupe DroneAtlas.
